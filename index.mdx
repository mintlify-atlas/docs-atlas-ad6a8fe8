GeoMine is the **Nearby Wells Intelligence System (NWIS)** — a real-time drilling risk platform that fuses machine learning, retrieval-augmented generation (RAG), GIS spatial filtering, and LLM-powered analysis to help drilling engineers identify and mitigate hazards before they escalate. Built for oil and gas operations in the Assam Shelf and similar basins, GeoMine processes live surface telemetry against a repository of historical offset well incidents to deliver actionable, context-aware risk assessments.

## What GeoMine Does

GeoMine ingests live drilling parameters — depth, ROP, RPM, torque, and WOB — and runs them through a multi-layer analysis pipeline:

<Steps>
  <Step title="ML Risk Scoring">
    A scikit-learn classifier trained on historical stuck pipe events scores current telemetry against five features and returns a risk level (SAFE → CRITICAL) with a 0–99 composite score.
  </Step>
  <Step title="GIS Spatial Filtering">
    Haversine distance queries identify offset wells within a configurable radius (default 5 km) around the active rig, loading their historical event records from PostgreSQL + PostGIS.
  </Step>
  <Step title="RAG Historical Intelligence">
    A retrieval-augmented generation pipeline (in-memory or pgvector backend, Gemini embeddings) matches the current depth and formation against past incidents to surface the most relevant analog evidence.
  </Step>
  <Step title="AI Summary & Mitigation">
    Google Gemini synthesizes the retrieved evidence into a plain-language operational directive with recommended mitigations, displayed in the Streamlit dashboard's live SCADA interface.
  </Step>
</Steps>

## System Components

| Component | Technology | Purpose |
|-----------|-----------|---------|
| Backend API | FastAPI + Uvicorn | REST endpoints, WebSocket, request validation |
| ML Engine | scikit-learn, joblib | Stuck pipe risk scoring |
| Historical Intelligence | Gemini + pgvector/in-memory RAG | Offset well evidence retrieval |
| GIS Engine | PostGIS, Haversine math | Spatial well filtering |
| OCR Pipeline | PyMuPDF, Tesseract, Ollama | Document data extraction |
| Dashboard | Streamlit, Folium, Altair | Interactive SCADA interface |
| Database | PostgreSQL 18 + PostGIS | Well event repository |
| Deployment | Docker Compose | Three-container stack (db, backend, dashboard) |

<Note>
GeoMine was developed for the Smart India Hackathon 2026. The system includes both a live production mode (PostgreSQL + Gemini API) and a fully offline fallback mode using cached mock events and pre-computed embeddings.
</Note>
